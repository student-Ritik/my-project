# Public hosting guide

## GitHub Pages
1. Create a GitHub repository and push this folder there.
2. In GitHub, go to Settings > Pages.
3. Choose GitHub Actions as the source.
4. Run the workflow from the Actions tab.
5. After deployment, GitHub will provide a public URL.

## Netlify
1. Go to https://netlify.com and sign in.
2. Click New site from Git.
3. Connect the GitHub repository.
4. Set publish directory to the site root.
5. Deploy.

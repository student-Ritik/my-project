
## 🖼️ गैलरी में तस्वीरें जोड़ें

```
aasram/
├── images/
│   ├── temple.jpg
│   ├── yoga-class.jpg
│   └── garden.jpg
└── index.html
```

### स्टेप 2: HTML में गैलरी अपडेट करें
**फाइल:** `index.html` में गैलरी सेक्शन खोजें

**पहले:**
```html

    <i class="fas fa-image"></i>
    <p>मुख्य मंदिर</p>
</div>
```

**अब बदलें में:**
```html
<img src="images/temple.jpg" alt="मुख्य मंदिर">
```

### स्टेप 3: CSS अपडेट करें
**फाइल:** `styles.css`

**खोजें:**
```css
.gallery-placeholder {
```

**जोड़ें:**
```css
.gallery-item img {
    width: 100%;
    height: 250px;
    object-fit: cover;
}
```

## 📧 फॉर्म को काम करने के लिए सेटअप करें

### वर्तमान में:
- फॉर्म स्थानीय रूप से काम करता है
- डेटा सहेजा नहीं जाता

### ईमेल के साथ काम करने के लिए:

**विकल्प 1: Formspree (सबसे आसान)**
1. https://formspree.io पर जाएं
2. साइन अप करें
3. अपना ईमेल जोड़ें
4. `index.html` में फॉर्म को अपडेट करें:

```html
<form action="https://formspree.io/f/YOUR_ID" method="POST" onsubmit="handleSubmit(event)">
```

**विकल्प 2: EmailJS**
1. https://www.emailjs.com पर जाएं
2. खाता बनाएं
3. HTML में जोड़ें:
```html
<script type="text/javascript" src="https://cdn.jsdelivr.net/npm/@emailjs/browser@3/dist/index.min.js"></script>
```

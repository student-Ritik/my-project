# कबीर आश्रम जयनगर - वेबसाइट

एक पेशेवर, प्रतिक्रियाशील वेबसाइट **कबीर आश्रम जयनगर** के लिए बनाई गई है।

## 📁 फाइल संरचना

```
aasram/
├── index.html      # मुख्य HTML फाइल
├── styles.css      # स्टाइलशीट
├── script.js       # JavaScript कार्यक्षमता
└── README.md       # यह फाइल
```

## ✨ विशेषताएं

- ✅ **पूरी तरह प्रतिक्रियाशील डिजाइन** - सभी उपकरणों पर काम करता है
- ✅ **हिंदी समर्थन** - पूरी तरह हिंदी में सामग्री
- ✅ **आधुनिक डिजाइन** - सुंदर रंग और लेआउट
- ✅ **मोबाइल मेनू** - हैम्बर्गर मेनू मोबाइल उपकरणों के लिए
- ✅ **सुचारु स्क्रोलिंग** - सभी लिंक के लिए सुचारु नेविगेशन
- ✅ **संपर्क फॉर्म** - आगंतुकों के लिए संदेश फॉर्म
- ✅ **गैलरी अनुभाग** - आश्रम के चित्रों के लिए

4. **गैलरी** - आश्रम की तस्वीरें

## 🚀 शुरुआत करें

1. सभी फाइलें एक ही फोल्डर में हैं
2. `index.html` को किसी भी ब्राउज़र में खोलें
3. वेबसाइट तुरंत लोड हो जाएगी

## ✏️ कस्टमाइज़ेशन गाइड

### संपर्क जानकारी अपडेट करें

`index.html` में संपर्क अनुभाग खोलें और निम्नलिखित अपडेट करें:

```html
<!-- Phone Number -->
<p>+91-80-XXXX-XXXX</p>

<!-- Email -->
<p>info@kabiraasram.org</p>

<!-- Address -->
<p>कबीर आश्रम, जयनगर<br>बेंगलुरु - 560069<br>भारत</p>
```

### कार्यक्रम जोड़ें या संपादित करें

`index.html` में `programs` अनुभाग में नई कार्ड जोड़ें:

```html
<div class="program-card">
    <div class="program-icon">
        <i class="fas fa-ICON-NAME"></i>
    </div>
    <h3>कार्यक्रम का नाम</h3>
    <p>कार्यक्रम का विवरण</p>
    <span class="time">समय विवरण</span>
</div>
```

### गैलरी में तस्वीरें जोड़ें

वर्तमान में प्लेसहोल्डर हैं। वास्तविक तस्वीरों के लिए:

```html
<div class="gallery-item">
    <img src="path/to/image.jpg" alt="विवरण">
</div>
```

और CSS में अपडेट करें:

```css
.gallery-item img {
    width: 100%;
    height: 250px;
    object-fit: cover;
}
```
